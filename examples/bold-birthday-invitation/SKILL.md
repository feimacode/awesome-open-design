# Bold Birthday Party Invitation

1. Create a portrait card canvas (480×672px) on a light gray background, with the card body using a warm cream (`#FBF4E9`) color and a subtle box-shadow.
2. Build the top 62% as a solid coral (`#FF4B33`) block containing the invitation headline content, centered vertically and horizontally.
3. Inside the coral block, add a small uppercase "Turning" eyebrow in cream at reduced opacity, a massive age numeral (`232px`, weight 900) in cream, and a bold "You're invited!" headline below.
4. In the lower cream section, place the guest name as a large bold heading in near-black ink color.
5. Below the name, add four detail rows (Date, Time, Location, RSVP), each with a coral uppercase label on the left and a placeholder value right-aligned, separated by thin horizontal rules.
6. Style the first row without a top border and adjust spacing for a clean, breathable layout.
7. Use only system sans-serif fonts (`-apple-system`, `"Segoe UI"`, `"Helvetica Neue"`, Arial, sans-serif) — no external fonts, no images, no decorative elements.
8. Keep the design purely typographic and high-contrast, relying on size, weight, and color blocking for visual impact.
